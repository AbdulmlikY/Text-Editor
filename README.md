
# Text Editor - Java Swing

This is a simple text editor application developed in Java using Swing.  
It was created as an assignment for the **Visual Programming** course.

## Features
- New: Clear the text area.
- Open: Load text from a file.
- Save: Save current text to a file.
- Exit: Close the application.

## Notes
- Built with Java Swing.
- Uses `JTextArea`, `JMenuBar`, `JFileChooser`, `FileReader`, and `FileWriter`.
- File I/O exceptions are handled with error messages.
